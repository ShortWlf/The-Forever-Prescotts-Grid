# Forever Prescotts Grid

Welcome to the official repository for the **Forever Prescotts** OpenSimulator grid. 

This project is built and maintained as a living memorial for **Joe Prescotts**, who passed away. Joe had a deep passion and a dream for a fishing system that he wanted to bring to life inside a game. This grid is the realization of that dream—a dedicated virtual space built in his remembrance, centered entirely around the peace, community, and joy of fishing.

---

## 🗺️ Grid Layout & Specifications

The Forever Prescotts grid is engineered to provide a massive, high-performance environment for creators, visitors, and virtual anglers alike. 

* **Total Regions:** 9 Varregions
* **Region Size:** 1024m x 1024m each
* **Capacity:** 80,000 Prims per region, allowing for incredibly detailed builds and environments without performance bottlenecks.

### ⚓ The Centerpiece: Memorial Island
At the absolute heart of the grid lies **Memorial Island**. This central region serves as the anchor for the entire project, housing **Joe's Fishing Dock and Pier**. It is designed as a tranquil space for visitors to gather, remember Joe, and cast a line in the waters that represent his ultimate vision.

---

## 🛠️ Repository Contents

This Git repository contains the core configuration files, server layouts, and region data required to host, back up, or deploy the Forever Prescotts environment. 

* `OpenSim.ini` / `Robust.ini` configurations optimized for high-prim Varregions.
* Region layout configurations (`regions.ini`).
* OAR/IAR backup templates and customized terrain maps.
* Community-contributed open-source LSL scripts and assets tailored for OpenSim fishing systems.
